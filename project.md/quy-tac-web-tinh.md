# Quy tắc cho Agent – Dự án web tĩnh

- Luôn trả lời và viết nội dung bằng **tiếng Việt có dấu**.
- Chỉ dùng **HTML, CSS, JavaScript thuần** + **Bootstrap 5 qua CDN**. Không dùng backend, không framework build (React, Vue…), không npm.
- Tách file rõ ràng: `index.html`, `css/style.css`, `js/main.js`. Không nhồi CSS/JS dài vào `index.html`.
- **Trước khi code**, giải thích ngắn cấu trúc thư mục và file nào chứa phần nào để người dùng biết sửa ở đâu.
- Mỗi section trong HTML có comment đầu/cuối, ví dụ `<!-- ===== HERO ===== -->`.
- Màu sắc khai báo bằng biến CSS trong `:root`, không viết cứng mã màu rải rác.
- Không tự bịa số điện thoại, email, địa chỉ, giá bán — để chỗ trống `[ĐIỀN ...]`.
- Code xong phải mở thử bằng trình duyệt, kiểm tra hiển thị máy tính + điện thoại và Console không lỗi.
