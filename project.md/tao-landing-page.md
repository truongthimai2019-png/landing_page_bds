# Workflow: Tạo landing page

1. Đọc file `PROMPT_landing-page-vinhomes.md` ở thư mục gốc.
2. Trình bày cấu trúc thư mục + nội dung từng file sẽ tạo, chờ người dùng đồng ý.
3. Tạo thư mục `vinhomes-landing/` với `index.html`, `css/style.css`, `js/main.js`.
4. Code lần lượt: Navbar → Hero → Features → Footer.
5. Chọn ảnh Unsplash cho Hero (bất động sản, biệt thự, Vinschool) và 3 card Features; kiểm tra ảnh hiển thị được.
6. Viết `js/main.js`: cuộn mượt, đóng menu mobile, fade-in khi cuộn, năm tự động ở footer.
7. Mở `index.html` bằng trình duyệt, kiểm tra ở khổ máy tính và điện thoại (375px), xem Console.
8. Đối chiếu từng mục "Tiêu chí hoàn thành" trong file PROMPT, báo cáo mục nào đạt/chưa đạt.
